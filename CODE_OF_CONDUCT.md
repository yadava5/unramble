# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, critique code rather than people, and keep discussion on
the work. Harassment, personal attacks and publishing anyone's private information are not
accepted, and the maintainer may remove comments, issues or pull requests that break this and
block the people who post them.

To report something privately, use GitHub's **Report content** on the comment or issue, or a
private vulnerability report on this repository if it involves security.
