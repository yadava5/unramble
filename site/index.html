Dictate it rough. Press Ctrl+G. Send what you meant.

unramble is a Claude Code plugin that rewrites the prompt you just dictated, in place: fillers and false starts gone, your correction applied, separate asks numbered. Same meaning, nothing added. Press Ctrl+G again and your original comes back. It runs on your Claude Code plan, with no API key.

Install in Claude Code

Opens Claude Code in your terminal with the install command typed in. Press Enter, answer y, then run /unramble setup once. The plugin reminds you.

The first time, your browser may ask to open Claude Code. Needs Claude Code installed. Or install by hand.

What it won’t do

Every rewrite is checked before it replaces your text.

  • Send anything you didn’t ask it to. Nothing leaves the box until you press Ctrl+G.
  • Lose a machine value. A rewrite that drops a path, --flag, number, URL, @ref or [Pasted text] chip is refused and your draft stays, unless you corrected that value on the spot.
  • Add a link or a command you never said. A rewrite that brings one in is refused. On 2,240 recorded rewrites, this check refused none.
  • Touch pasted logs or code. They are masked before the model sees the draft and put back byte for byte.
  • Answer your question or do the task. “Can you check X?” stays a question for Claude Code.
  • Overwrite you. If you typed while it ran, your text wins.

Where it falls short

  • Terminal UI only. It works in claude run in a terminal, including the one inside VS Code or Cursor. The VS Code extension’s chat panel and the desktop app are not supported.
  • Long pastes stay as chips. When a dictation app pastes a long block, Claude Code folds it into a [Pasted text #N] chip that plugins cannot read (as of 2.1.308), so that text is kept as is. Claude Code’s built-in voice input, macOS Dictation and typing all work fully.
  • Garbled speech stays garbled. If the transcription is wrong in a way context cannot fix, the rewrite keeps it as heard rather than guess. Add the name to Names you often say in its settings.
  • A short window can hide the band. In an 80×24 window with a tall status line, Claude Code may not draw the ⌃G refine row. Ctrl+G still works.
  • The plugin API is early access. CI runs the newest Claude Code every day to catch a release that moves it.

Runs on your plan

It calls the model through your Claude Code session’s own login, billed to your subscription like any prompt. No API key, no network code and no server anywhere in the plugin.

Each rewrite is one short call: about 3k tokens of rules, cached after the first rewrite, plus your words. Choose the model in /config: sonnet, fast and light on your plan, or opus, the most faithful.

Sends
On Ctrl+G only: your draft, with pasted logs and code masked out, plus its rules, to the model through Claude Code’s own session. Nothing else leaves your machine.
Writes
keybindings.json, only when you run /unramble setup, keeping your original beside it as keybindings.json.unramble-backup. And your prompt box, only when you press Ctrl+G.
Reads
Its own rules, keybindings.json, and the environment variables that find your config folder. It never reads your conversation, history or project files.
Runs
No commands and no processes. It adds one slash command, /unramble.

CI also tests the newest Claude Code every day on Linux, macOS and Windows. Not yet tried by hand: iTerm2, Windows Terminal and Kiro’s terminal. If one does not work, please open an issue.

Install by hand

If the button above does not open Claude Code, either of these does the same thing.

In your terminal

zsh, bash or PowerShell, not inside Claude Code. Needs Node 18+.

npx unramble

Or inside Claude Code

One line at a time. No Node needed.

  1. /plugin install unramble --marketplace yadava5/unramble
  2. /unramble setup

Answer y to add the marketplace. Setup binds Ctrl+G, keeps a backup of your keybindings.json and never overwrites a key you bound yourself. Either way, start a new Claude Code session afterwards, say or type a prompt, and press Ctrl+G.

Update

npx unramble update

Uninstall

npx unramble uninstall

Takes back only the two Ctrl+G bindings setup added.
